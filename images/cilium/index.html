Root, shell and open findings

Root
The agent programs the node's network in the kernel, which the chart runs it privileged to do.
A shell
The runtime's bash, which the agent's init scripts run in.
C libraries
1 critical and 4 high, in glibc and the other C libraries the program links. None has a fixed release to take. The critical is CVE-2019-1010022 in glibc, which glibc’s maintainers do not treat as a security bug.

How it was tested

Run on a read-only root, as root, which it needs, with no network beyond its own.

  • The agent came up runtime: cilium-dbg status says OK
  • It made cilium_host and cilium_vxlan
  • It registered the node's CiliumNode and its host endpoint, with the datapath its runtime's clang compiled loaded

With its Helm chart
