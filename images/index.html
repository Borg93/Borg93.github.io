Switching to one

Same version tag

Each image keeps the project’s version tag and is tested with the arguments its own chart gives it. Change the registry in your chart’s values or your manifest. The pages of 38 images, Argo CD, cert-manager, Cilium, Flux and Harbor among them, give the values to paste.

Pin by digest

When a fix lands, the tag moves to the new build. Old digests stay pullable for 24 months.

Not a base image

Most images have no shell, so a Dockerfile RUN fails. Use COPY --from= to take the program into your own image.

Debugging

kubectl debug attaches a shell beside a running container. Each image page gives the command.

Taking an image across an air gap

A plain pull and push leaves the documents behind, because they are attached to the digest and are not part of the image. Copy the image with what is attached to it, and check the signature from the copy.

# outside: the image and everything attached to it, into a folder
$ oras cp -r registry.placeholder.example/argocd:v3.5.6 --to-oci-layout ./carry:v3.5.6

# on the site: from the folder into your own registry
$ oras cp -r --from-oci-layout ./carry:v3.5.6 registry.example.internal/argocd:v3.5.6

# check the signature with the key you carried, from a saved copy
$ cosign save registry.example.internal/argocd:v3.5.6 --dir ./argocd
$ cosign verify --key images.pub --local-image ./argocd

oras marks -r as a preview feature. For a whole site in one signed file, see Innergård.
