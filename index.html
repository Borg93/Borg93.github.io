Evidence you can hand over

When an auditor or a customer asks what is in your software and where it came from, the answer is attached to the image. The build is made for SLSA Build Level 3, the highest level the standard defines, with every signature entered in a tamper-evident transparency log hosted in the EU. You can read and check every document without an account.

image

argocd

v3.5.6

  • SBOM CycloneDX, every package in the image, and the same in SPDX
  • VEX statements every open finding and why it is still there, as OpenVEX and CSAF 2.0
  • Scan the Trivy and Grype reports from the publish date
  • Provenance which commit it was built from and every input, as an in-toto statement, at SLSA Build Level 3, the highest the standard defines

Also with every image: a signature (cosign, at the digest, with one public key you copy once, and an entry in a tamper-evident transparency log hosted in the EU); its sources (the URL and hash of every source it was built from); two architectures (linux/amd64, and linux/arm64).

Why us

Four things that let us keep the promise, where doing it yourself does not scale and buying it from outside the EU leaves you dependent.

    Agents do the work that grows

    Keeping images current is work that grows with every CVE. A team cannot hire its way out of it. Here agents triage, patch and rebuild, and a person signs off, so the catalogue stays current as the numbers rise.

    Built with Nix, from source

    Every input is pinned, and every image is built from the project’s own source at a commit the catalogue names. The same build gives the same image again, so what you run can be traced and repeated.
